# Projeto 02 — Coluna semanal de um advogado em revista especializada

## Objetivo

Automatizar a criação de uma coluna jurídica para uma revista especializada utilizando inteligência artificial.

O advogado fornece uma ideia, uma narrativa e o objetivo do texto. A IA organiza as informações e produz um rascunho para revisão do autor.

## Funcionamento

1. Ler os documentos da pasta `apoio/`.
2. Seguir as instruções de `docs/protocolo.md`.
3. Gerar o rascunho da coluna jurídica.
4. Salvar o resultado na pasta `saida/`.
5. Registrar o teste em `docs/registro.md`.

Todos os dados utilizados neste projeto são fictícios.
